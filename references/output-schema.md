# 输出表格 Schema

第 4 步汇总时必须按本文件的字段与格式产出。

## 必需字段（每店一行，按此列序输出）

**展示列序（用户定制，按此顺序输出，勿打乱）**：门店 → 利用政策/优惠 → 所在位置/载体 → 临停价格 → 停车载体 → 充电免停 → 地址 → 可信度。

| 字段 | 说明 | 示例 |
|---|---|---|
| 门店 | 门店全称（含分店标识） | 盖饭邦·长沙菜馆(合生汇店) |
| 利用政策/优惠 | 免费时长、消费满额送时、积分兑换、会员权益、活动期政策。**只填现时有效的政策；已查证过期的政策直接剔除，不得写入** | 500积分抵1小时；月卡会员每月3次免费1小时 |
| 所在位置/载体 | 直接标注**商场/商圈/商业街名称**，或**街边店**。不区分"店型"概念，能定位即可 | 合生国际广场 / 新天地时尚Ⅰ / 街边店 |
| 临停价格 | 单位单价（元/小时或元/半小时）；**无公开数据须如实标"未公开"** | 12元/小时（超30分钟） |
| 停车载体 | **写实填写，不得假设**：先标载体有无自建停车设施（已核实有/已确认无/未知），再写具体停车场/车库名，或临街道路停车。**禁止只写"XX广场停车"这类未经核实的内容** | "已核实有：合生国际广场地下车库" / "已确认无自建车位，临街道路停车10元/小时" / "未知" |
| 充电免停 | 仅商场/综合体配套车位必查：有无充电桩、充电免停条件（如"充电满60分钟免停2小时"）。**查不到标"充电免停政策未知"，不得默认免费** | 有充电桩，充电满60分钟免停2小时 / 充电免停政策未知 |
| 地址 | 完整地址 + 所在区 | 翔殷路1099号合生国际广场B1层（杨浦） |
| 可信度 | 已核实 / 待确认 | 待确认 |

> 其余非展示列（停车环境、优惠限时/时段、最近停车点距离、数据来源、更新日期）作为补充信息保留，若用户需要可附加输出。

## 停车载体填写规则（强制性）

1. **先答"载体有没有"，再答"怎么停"**：对每个门店所在载体，先确认是否有自建停车设施（地下车库/专属停车场/路面划线停车场），依据载体官网、招商资料、地图 POI 子项、本地宝名录。
2. 输出三态：**已核实有 / 已确认无 / 未知**。未确认前严禁填写假设性停车内容。
3. **只认同属性商业配套车位**：停车载体必须是商场车库、商业街/商圈临停、楼宇对外车库、门店自有车位。**禁止把同地址的住宅小区包月车位、酒店专属车位、办公租户车位等"非顾客可停"资源算作该店停车设施。** 若只搜到此类资源，应标"该店可停配套未确认"，并注明"这些车位为住宅/酒店/办公所有，非本店顾客可用"。
4. 载体无自建设施时，**必须查临街/道路停车**（政府"智慧道路停车场"公示、停车收费标志牌），填写"已确认无自建车位，临街道路停车X元/小时"。
5. UGC 实地信息（小红书/抖音/点评评论）可作补充证据，但来源必须标注"用户反馈"，可信度标"待确认"。

## 最近停车点筛选标准（强制性，执行于第 3 步）

当门店无自有/可用停车位、需查"最近停车点"时，按以下标准筛选：

1. **三选一，满足任意一条即入选**：① **有消费免停**；② **有充电免停**；③ **临停 ≤8元/时**。三条任一满足即作为推荐停车点。
2. **三条都不满足的停车场不入选**（即使距离最近）——不得为了凑"最近"硬塞不达标的。
3. **在入选者中按距离由近到远推荐**；同等距离优先选免停力度大的。
4. 若附近合理半径（如 1km）内无任何符合三选一的停车场，如实标注"该店周边 1km 内无符合条件（消费免停/充电免停/≤8元时）的停车场"，列出最低价真实选项供参考并注明未达标项，**不得虚构达标选项**。

## 去重归并规则（强制性，执行于第 1 步）

1. **同一主体/载体优先合并**：当多个门店落在同一载体（同一商业街、同一楼宇、同一园区）时，先判断是否为同一主体（注册主体、关联电话、相邻铺面）。是同一主体 → **合并为一行**，不得仅凭门牌号（如 138 号 / 148 号）拆成多行。
2. 证据方向：工商注册主体（如"某餐饮店"覆盖多个门牌）、关联电话、同一商业街相邻铺面 → 视为同一店。
3. 确认合并后，在"门店"列保留主名（如"北翟路店"），可在备注注明其包含的多个铺面。
4. 只有主体确实不同（独立注册、独立名称的加盟/子品牌）时，才拆行并各自核实。
